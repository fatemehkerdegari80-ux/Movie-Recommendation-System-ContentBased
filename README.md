# Movie Recommendation System

## Overview

This project builds a movie recommendation system based on movie genres and user ratings.

The notebook uses collaborative filtering and content-based filtering concepts to recommend movies to users according to their interests and previously rated movies.

The project is implemented in Python using pandas and NumPy inside a Jupyter Notebook.

---

## Technologies Used

- Python
- Jupyter Notebook
- pandas
- NumPy
- matplotlib

---

## Project Goal

The main objective of this project is to recommend movies to users based on:

- Movie genres
- Similarity between movies
- User rating behavior

The recommendation system analyzes movie features and user preferences to generate personalized movie suggestions.

## Project Workflow

### 1. Import Required Libraries

```python
import pandas as pd
from math import sqrt
import numpy as np
import matplotlib.pyplot as plt
```

---

### 2. Load Datasets

The datasets are loaded using pandas.

```python
movies_df = pd.read_csv('movies.csv')
ratings_df = pd.read_csv('ratings.csv')
```

---

### 3. Data Cleaning

Movie titles contain release years inside parentheses.

The notebook extracts:

- Movie release year
- Clean movie title

```python
movies_df['year'] = movies_df.title.str.extract('(\(\d\d\d\d\))', expand=False)
movies_df['year'] = movies_df.year.str.extract('(\d\d\d\d)', expand=False)

movies_df['title'] = movies_df.title.str.replace('(\(\d\d\d\d\))', '')
movies_df['title'] = movies_df['title'].apply(lambda x: x.strip())
```

---

### 4. Genre Processing

Movie genres are separated into lists using:

```python
movies_df['genres'] = movies_df.genres.str.split('|')
```

Example:

```python
Action|Adventure|Fantasy
```

becomes:

```python
['Action', 'Adventure', 'Fantasy']
```

---

### 5. Genre Encoding

Genres are converted into binary values (0 and 1).

For each genre:

- `1` → Movie belongs to the genre
- `0` → Movie does not belong to the genre

This creates a genre matrix suitable for recommendation algorithms.

---

### 6. User Input Movies

The notebook allows users to provide a list of movies and ratings.

Example:

```python
userInput = [
    {'title':'Toy Story', 'rating':3.5},
    {'title':'Jumanji', 'rating':2.0}
]
```

---

### 7. Recommendation Logic

The recommendation engine compares:

- User preferences
- Movie genres
- Similarity scores

Weighted scores are calculated to determine the best movie recommendations.

---

### 8. Generate Recommendations

Movies with the highest recommendation scores are displayed to the user.

The final output contains personalized movie suggestions based on genre similarity and user ratings.

Recommendations are generated by analyzing:
